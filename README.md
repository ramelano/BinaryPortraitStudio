# Binary Portrait Studio

An interactive, single-file HTML5 Canvas application that transforms any photo into an animated `0` and `1` binary particle portrait.

🔗 **Live Demo:** https://ramelano.github.io/BinaryPortraitStudio/

## Features
- **Instant Image Processing:** Supports `.JPG`, `.PNG`, `.WEBP`, and Apple `.HEIC` formats directly in the browser (client-side, no server upload).
- **Color Palettes:** Amber & Copper, Crimson & Gold, Original Photo Colors, Matrix Green, and Silver Monochrome.
- **Physics & Motion Modes:** Cinematic Wave & Breath, Vortex Assemble, and Interactive Cursor Field.
- **Export Options:** Save high-resolution `PNG` snapshots or export a standalone offline `.html` file with your portrait embedded.
- **Bilingual UI:** Instant toggle between English (`EN`) and Turkish (`TR`).

## Usage
Open the live demo link or run `index.html` locally in any modern web browser—no build tools or dependencies required.
